# Profile assets

The terminal animation uses Nitesh's public GitHub profile photo. Render it with `python3 tools/render_terminal.py` after installing Pillow and NumPy.

The metrics script uses only public, owned repositories. The workflow refreshes the panels and discovers deployment links daily and on profile changes. It uses the repository's built-in GitHub token. See `tools/README.md` for live-project catalog rules.

Technology logos come from Devicon, with its MIT license included in `icons/DEVICON-LICENSE.txt`. SQL, Excel and Power BI marks are simplified vector artwork.
